# DSO Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a safe, student-facing conversational DSO Copilot that answers grounded questions from latest compliance state plus curated federal/university knowledge sources.

**Architecture:** Add a separate LangGraph chat workflow with four focused nodes: state loader, intent router, context retriever, and synthesizer. Introduce a dedicated DSO corpus/index pipeline backed by ChromaDB, keep Gemini as the reasoning model, and expose a typed read-only chat API that enforces no-math, escalation, and grounding rules.

**Tech Stack:** FastAPI, LangGraph, SQLAlchemy, Pydantic, ChromaDB, Gemini via Google GenAI SDK, pytest

```python
class SchoolResolver:
    def __init__(self, aliases: dict[str, str]) -> None:
        self._aliases = {key.casefold(): value for key, value in aliases.items()}

    def resolve(self, school_name: str | None) -> str | None:
        if not school_name:
            return None
        return self._aliases.get(school_name.casefold())
```

```python
class HybridDSORetriever:
    def search(self, query: str, *, scope: str, school_key: str | None, top_k: int = 5) -> list[DSOCitation]:
        filtered = self._filter_documents(scope=scope, school_key=school_key)
        # combine lexical overlap + vector similarity score
        return sorted(filtered_results, key=lambda item: item.score, reverse=True)[:top_k]
```
